# generals.ts 调整记录

本文件保存 generals.ts 的历史修改痕迹；代码文件本身只保留最终版。

## 2026-11-13 新增田畴、高览、崔琰、张翼

- 新增田畴（`tianchou`，3 血男群）：善刀。洛书池归入辅助（`support`）。
  - 善刀：出牌阶段限一次，将任意名角色的各一张牌置于牌堆顶，视为对这些角色使用一张【五谷丰登】，然后视为对除这些角色外的其他角色使用一张【万箭齐发】。
  - 实现口径：发动时由玩家点选角色集合（可多选，跳过没有牌的角色），引擎按“手牌价值最低优先、其次装备区、最后判定区”各取一张置顶（`deck.unshift`，后取的压在上面）。五谷丰登的牌数等于被取牌的角色数，只对被取牌的角色逐个询问（沿用 `HARVEST_PICK`，牌不够时剩余进弃牌堆）。万箭齐发的目标 = 所有存活角色 ∖ 被选中角色，**恒不包含田畴自己**（即使他没被选中）；目标按角色集合逐个入队 `AOE_DODGE`，仍尊重【藤甲】【智迟】的免疫与无懈可击窗口。两次结算共用虚拟 ♥A【万箭齐发】牌 id，好让无懈/响应日志可读。
- 新增高览（`gaolan`，4 血男魏）：峻攻、等力。洛书池归入菜刀（`blade`）。
  - 峻攻：出牌阶段，弃置 X 张牌或失去 X 点体力（X = 本阶段此前发动次数 +1），视为使用一张无距离次数限制的【杀】，然后当此【杀】造成伤害后，此技能失效直至本回合结束。
  - 实现口径：X 用 `jungongCount`（出牌阶段重置）计数；代价二选一，弃牌需要手牌+装备合计 ≥ X，失去体力需要当前体力 > X（否则不提供该项，两项都不成立时直接拒绝发动）。视为使用的【杀】通过 `useVirtualSlash` 的 `noRange` + `noLimit` 创建（不计次数、无距离）。伤害结算走 `dealDamage` 的牌 id 钩子（`jungongSlashId`），只有这张【杀】真的造成伤害才把 `jungongDisabledTurn` 置为本回合序号；被【闪】抵消则不失效，可以继续以更高的 X 再发动。
  - 等力：当你使用【杀】指定一名角色为目标时，或当你成为其他角色使用【杀】的目标时，若你与其体力值相等，你可以摸一张牌。
  - 实现口径：在【杀】的目标确定后逐目标询问（使用者一侧与目标一侧各问一次，均按“双方当前体力值相等”过滤），不相等不询问。
- 新增崔琰（`cuiyan`，3 血男魏）：雅俊、尊嫡。洛书池归入辅助（`support`）。
  - 雅俊：①摸牌阶段，你多摸一张牌；②出牌阶段开始时，你可以用一张本回合获得的牌与一名其他角色拼点，若你赢，你可以将其中一张拼点牌置于牌堆顶；若你没赢，你本回合的手牌上限-1。
  - 实现口径：①走 `drawForTurn` 的 +1 分支；②在 `beginActionPhase` 询问，候选牌限定为本回合获得的牌（`gainedCardIdsThisTurn`，摸牌阶段到手的牌在摸牌时当场写入，避免“第X阶段开始”时还没统计到）。拼点走 `pindianStart` 同一套流程（`state.pindian.skillId = 'cuiyan_yajun'`），引擎侧兜底校验发起者只能提交本回合获得的牌。赢则给出“把哪一张拼点牌置于牌堆顶 / 不放置”的选项（两张都来自弃牌堆，可任选）；没赢则 `handLimitDelta -= 1`。
  - 尊嫡：出牌阶段限一次，弃置一张手牌并选择一名角色，然后进行一次判定：黑色其摸三张牌；红色其可以移动场上的一张牌。
  - 实现口径：判定走 `performSkillJudge` / `resolveSkillJudge` 的新类型 `zundi`（鬼才/缓释/鬼道介入后仍按同一 `extraContext.zundiTargetIndex` 结算）。黑色：目标摸三张（`drawForGeneral`）。红色：目标先确认是否移动，再依次选“装备来源 → 获得者”，复用与巧变相同的搬装备逻辑（含被替换装备进弃牌堆）；场上没有装备时直接跳过。不选目标时默认以自己为目标。
- 新增张翼（`zhangyi`，4 血男蜀）：执义。洛书池归入肉盾（`tank`）。
  - 执义：锁定技，一名角色的结束阶段，若你本回合使用或打出过基本牌，你选择一项：1.视为使用任意一张你本回合使用或打出过的基本牌；2.摸一张牌。
  - 实现口径：插在 `runEndPhaseSkills`，遍历全场（含张翼自己）的结束阶段，按 `basicUsedThisTurn` 逐张给出“视为使用”选项；【闪】不能主动使用故不作为选项，【桃】只在已受伤时出现，【杀】类需要攻击范围内有合法目标（无合法目标时只留“摸一张牌”）。选项 1 通过 `useVirtualSlash` 使用（火/雷杀保留属性），【桃】直接回复、【酒】直接醉；选项 2 摸一张。锁定技默认一定会结算：界面上的“放弃”按选项 2 处理，保证队列不卡死。
  - 补齐“打出”记录：出【闪】（含 AOE 万箭）、出【杀】响应南蛮/决斗、濒死出【桃】/【酒】的路径现在都会写入 `basicUsedThisTurn`（原实现只记录“使用”）。
- 洛书池新增 4 名（辅助 +田畴/崔琰，菜刀 +高览，肉盾 +张翼），并在 `POSITION_ROLE_BY_ID` 登记定位。
- 界面：三个主动技能（善刀/峻攻/尊嫡）进入技能按钮栏并给出操作提示；雅俊②、峻攻、尊嫡移装备、执义、等力的询问都由通用 `SKILL_ACTIVATE_CONFIRM` 选项渲染；AI 侧为上述每个询问都写了决策分支（等力/尊嫡自动确认、峻攻优先弃废牌、雅俊手牌不吃紧才拼点、执义优先斩杀/回血否则摸牌）。

## 2026-11-13 新增文鸯；欢乐成双 / 斗地主支持本地对战

- 新增文鸯（`wenyang`，4 血男魏）：却敌、仇决、椎锋。
  - 却敌：每回合限一次，当你使用【杀】或【决斗】指定一名角色为唯一目标后，你可以选择一项：1.获得该角色的一张手牌；2.弃置一张基本牌，令此牌造成的伤害+1。你可以同时选择两项，若如此做，你减1点体力上限。
  - 仇决：锁定技，当你杀死其他角色后，你加1点体力上限并摸两张牌，然后你本回合发动“却敌”的次数上限+1。
  - 椎锋：出牌阶段限两次，你可以失去1点体力，视为使用一张【决斗】，然后若你因此受到伤害，你防止此伤害且本阶段此技能失效。
- 洛书池新增文鸯，定位为菜刀。
- 本地对战扩展至欢乐成双与斗地主：同一窗口分两屏，暖/冷或地主/农民各由一名本地玩家操作；选将阶段双方各自选择本方席位，不跑 AI，复用到断点续局与再战。

## 2026-11-12 界荀彧节命调整与新增吴景

- 界荀彧（`xunyu`）：节命改为二选一——①令一名角色摸X张牌，然后其将手牌弃置至X张（X为其体力上限且至多为5）；②令一名角色摸两张牌，然后若其手牌数小于体力上限，你可以摸一张牌。
- 新增吴景（`wujing`，4 血男吴）：合击、流兵。
  - 合击：当一名角色对其他角色使用仅指定一个目标的【决斗】或红色【杀】结算结束后，你可以对该目标角色使用一张无距离与次数限制的【杀】或【决斗】，然后若你使用的牌不为转化牌，你随机获得一张红色牌。
  - 流兵：锁定技，①当你于出牌阶段内使用第一张非虚拟【杀】时，此牌的花色视为♦；②当其他角色于其出牌阶段内使用非转化的黑色【杀】结算结束后，若此牌未造成过伤害，你获得之。
- 洛书池新增吴景，定位为菜刀。
