# 统率三军武将位置评分

> 生成命令：`npm run report:position > ../docs/position-scores.md`
> 口径：位置适配分，不含武将基础强度（`scoreGeneral`）、配合（`team`）与对位（`rival`）。
> 位置职责：冷主帅=先手限制暖二连；暖 B=暖二连先手爆发；冷 B=承接冷四连；暖主帅=回合外支援。
> 定位由使用者划定；未登记武将回退旧定位表。
> 冷方先行动前锋 A，暖方先行动前锋 B；两套分数按各自先手/后手职责分别计算。
> 分数越高，越适合该位置；同分时按武将名称排序。
