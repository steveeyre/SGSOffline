# 三国杀单机版

**版本 1.0.0** ｜ 纯前端单机对战 ｜ 无需注册、无需联网

复刻三国杀「统率三军」3v3、欢乐成双 2v2、斗地主 3 个单机玩法。对局由基于规则算法的电脑接管对方阵营，全部逻辑在浏览器内运行；也可以在同一台电脑上分屏本地对战（三种模式均支持）。

---

## 游戏模式

| 模式 | 阵营 | 说明 |
|------|------|------|
| **统率三军** | 冷 vs 暖 | 双方各 3 名武将（主帅 + 2 前锋），击败对方主帅获胜；保留大回合与行动单元机制 |
| **斗地主** | 地主 vs 农民 | 地主 1 将（暖方主帅）对两名农民（冷方前锋，共用一个玩家）；地主拥有飞扬、跋扈，全场拥有强易 |
| **欢乐成双** | 冷 vs 暖 | 4 名武将，1、4 号位属冷方，2、3 号位属暖方；玩家与 AI 各控制两个座位（本地对战时双方各控一侧）；1 号位先手但初始手牌少 1 张 |

### 对局配置

- **武将池**：洛书版（196 将）、平衡扩展版（60 将）、平衡版（40 将）、2013 版（32 将）
- **牌堆**：156 张军争 / 108 张标准（洛书版、平衡版只能配 156 张）
- **随机种子**：留空则随机；结算页会给出本局种子，填入即可复现同一局
- **本地对战**：统率三军、斗地主、欢乐成双均可选择「本地对战」，两名玩家在同一设备上分屏操作；斗地主为地主 vs 农民，欢乐成双为暖方（2、3 号位）vs 冷方（1、4 号位）
- **对局日志**：大厅右上角可导出本机保存的对局日志（含每一步的操作、决策快照与候选动作得分）

## 规则实现

- 规则引擎完全运行在浏览器内，没有后端依赖：选将、部署、行动单元、响应链与濒死结算都在前端完成
- 108 / 156 张牌堆、装备、延时锦囊、判定、拼点、觉醒/限定技等
- 响应队列统一处理「使用杀 → 出闪 → 鬼才 → 天香 → 濒死求桃」等链式交互
- 规则 AI 分四层：出牌评分（ai-policy）、公开信息记忆（ai-memory）、结果预测（ai-forecast）、集火与意图分析（ai-strategy），只使用公开信息，不读取对手暗牌

## 快速开始

### 方式一：构建离线单文件

离线包属于构建产物，不纳入版本控制，需要本地生成：

```bash
npm install
npm run build:standalone
```

构建完成后双击仓库根目录的 `SGSOffline.html` 即可开玩。武将原画已内嵌，不需要联网，也不需要启动服务。

> 离线包不包含背景音乐。需要 BGM 时，把 `bgm.flac` 放到生成的 html 同目录即可。

### 方式二：从源码运行

环境要求：Node.js >= 18，npm >= 9。

```bash
npm install
npm run dev:client      # http://localhost:5174
```

Windows 下也可以直接双击仓库根目录的 `SGSOffline.html`：不装依赖、不起服务、不打开终端窗口，也不会启动任何本地模型服务。该文件是构建产物，不入库，需要时用 `npm run build:standalone` 重新生成。

## 构建

```bash
npm run build             # 构建 shared / client
npm run build:standalone  # 生成根目录的离线单文件 SGSOffline.html
```

根目录的 `SGSOffline.html` 属于构建产物，已加入 `.gitignore`，不会提交到仓库。

## 自检

```bash
npm run check   # 统率三军、斗地主、欢乐成双三套引擎规则检查
```

引擎检查覆盖技能结算、响应队列、濒死救援、胜负判定等关键路径；改动规则后应先跑通再提交。

## 项目结构

```
SGSOffline/
├── client/                    React 前端 + 游戏引擎
│   ├── public/generals/       武将原画（217 张 webp）
│   ├── scripts/               引擎自检、离线打包、审计脚本
│   └── src/
│       ├── engine/            卡牌、武将、回合、AI、本地对局调度
│       ├── modes/             斗地主（FightTheLandlord）、欢乐成双（HappyPair）
│       ├── pages/             大厅、选将、对战、本地对战、结算
│       ├── store/             Zustand 状态
│       └── actions.ts         页面操作 → 本地引擎的派发层
├── shared/                    引擎与页面共用的类型定义
├── docs/                      开发文档与 AI 设计说明
├── SGSOffline.html            离线单文件（构建生成，不纳入版本控制）
└── package.json               npm workspaces 根配置
```

## 资源说明

- **武将原画**：`client/public/generals/`，共 217 张 webp，已随仓库提供
- **BGM**：`bgm.flac` 体积较大，未纳入仓库。可自行放置到 `client/public/` 后重新执行 `npm run build:standalone`，或直接放到离线包同目录
- **对局日志**：保存在浏览器 localStorage，可通过大厅的导出按钮下载

## 已知限制

- 对局 AI 全部由规则引擎实现，不接入本地大模型；`client/scripts/audit/` 下的复盘脚本仍可选装 Ollama，但只用于离线调参，与游戏运行无关
- `docs/DEVELOPMENT.md` 描述当前 1.0 结构；更细的 AI 设计见 `docs/` 下的专题文档
