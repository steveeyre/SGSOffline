# 三国杀 3v3 单机版

**版本 1.0.0** ｜ 纯前端单机对战 ｜ 无需注册、无需联网

复刻三国杀「统率三军」3v3 竞技模式，并加入斗地主、欢乐成双两个单机玩法。对局由规则 AI 接管对方阵营，全部逻辑在浏览器内运行；也可以在同一台电脑上两人轮流操作（本地对战）。

---

## 游戏模式

| 模式 | 阵营 | 说明 |
|------|------|------|
| **统率三军** | 冷 vs 暖 | 双方各 3 名武将（主帅 + 2 前锋），击败对方主帅获胜；保留大回合与行动单元机制 |
| **斗地主** | 地主 vs 农民 | 地主 1 将（暖方主帅）对两名农民（冷方前锋，共用一个玩家）；地主拥有飞扬、跋扈，全场拥有强易 |
| **欢乐成双** | 冷 vs 暖 | 4 名武将，1、4 号位属冷方，2、3 号位属暖方；玩家与 AI 各控制两个座位；1 号位先手但初始手牌少 1 张 |

### 对局配置

- **武将池**：洛书版（146 将）、平衡版（62 将）、2013 版（32 将）
- **牌堆**：156 张军争 / 108 张标准（洛书版、平衡版只能配 156 张）
- **随机种子**：留空则随机；结算页会给出本局种子，填入即可复现同一局
- **本地对战**：统率三军模式下选择「本地对战」，两名玩家轮流在同一设备上操作
- **对局日志**：大厅右上角可导出本机保存的对局日志（含每一步的操作、决策快照与候选动作得分）

## 规则实现

- 服务端权威的完整规则引擎已迁移为浏览器内引擎，支持选将、部署、行动单元、响应链与濒死结算
- 108 / 156 张牌堆、装备、延时锦囊、判定、拼点、觉醒/限定技等
- 响应队列统一处理「使用杀 → 出闪 → 鬼才 → 天香 → 濒死求桃」等链式交互
- 规则 AI 分四层：出牌评分（ai-policy）、公开信息记忆（ai-memory）、结果预测（ai-forecast）、集火与意图分析（ai-strategy），只使用公开信息，不读取对手暗牌

## 快速开始

### 方式一：构建离线单文件

离线包属于构建产物，不纳入版本控制，需要本地生成：

```bash
npm install
npm run build:standalone
```

构建完成后用浏览器打开 `release/SGS3v3.html`。武将原画已内嵌，不需要联网，也不需要启动服务。

> 离线包不包含背景音乐。需要 BGM 时，把 `bgm.flac` 放到生成的 html 同目录即可。

### 方式二：从源码运行

环境要求：Node.js >= 18，npm >= 9。

```bash
npm install

# 单机对战只需要前端
npm run dev:client      # http://localhost:5174

# 或同时启动前后端（含联机/本地模型实验接口）
npm run dev             # 前端 5174，后端 3001
```

## 构建

```bash
npm run build             # 构建 shared / client / server
npm run build:standalone  # 生成离线单文件 release/SGS3v3.html
```

`release/` 下的离线包属于构建产物，已加入 `.gitignore`，不会提交到仓库。

## 自检

```bash
npm run check   # 统率三军、斗地主、欢乐成双三套引擎规则检查
```

引擎检查覆盖技能结算、响应队列、濒死救援、胜负判定等关键路径；改动规则后应先跑通再提交。

## 项目结构

```
SGSOffline/
├── client/                    React 前端 + 游戏引擎
│   ├── public/generals/       武将原画（164 张）
│   ├── scripts/               引擎自检、离线打包、审计脚本
│   └── src/
│       ├── engine/            卡牌、武将、回合、AI、本地对局调度
│       ├── modes/             斗地主（FightTheLandlord）、欢乐成双（HappyPair）
│       ├── pages/             大厅、选将、对战、本地对战、结算
│       ├── store/             Zustand 状态
│       └── socket/            Socket.IO 封装（本地对局时直接转发到引擎）
├── server/                    联机房间与本地模型实验（1.0 单机流程不使用）
├── shared/                    前后端共享类型与通信协议
├── docs/                      早期 3v3 联机版的 PRD 与开发文档
├── release/                   离线单文件产物目录（构建生成，不纳入版本控制）
├── start-local-ai.bat         早期 Ollama 本地模型启动脚本（1.0 默认使用规则 AI）
└── package.json               npm workspaces 根配置
```

## 资源说明

- **武将原画**：`client/public/generals/`，共 164 张，已随仓库提供
- **BGM**：`bgm.flac` 体积较大，未纳入仓库。可自行放置到 `client/public/` 后重新执行 `npm run build:standalone`，或直接放到离线包同目录
- **对局日志**：保存在浏览器 localStorage，可通过大厅的导出按钮下载

## 已知限制

- 1.0 以单机对战为主；`server/` 是早期联机房间与本地模型实验代码，在线模式不在本版本的支持范围内
- `start-local-ai.bat` 为历史实验脚本，当前大厅不会启用本地模型 AI
- `docs/` 中的 PRD、开发文档描述的是最初 3v3 联机版本，部分内容已与单机版不一致，接口与结构请以源码为准
